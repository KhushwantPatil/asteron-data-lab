ASTERON DATA LAB — 200 SQL PROBLEMS
====================================

Use these in order. Problems 1–100 are the core curriculum. Problems 101–200 are the second level.

RULES
-----
1. Try each problem yourself first.
2. Inspect the data before assuming what a column means.
3. Be suspicious of totals.
4. Do not assume every invoice, order, customer mapping, or status is valid.
5. Save useful queries.
6. For business questions, write a one-line conclusion after the SQL result.
