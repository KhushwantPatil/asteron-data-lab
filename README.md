# Asteron Data Lab

## End-to-End Business Analytics Project

Asteron Data Lab is an independent analytics project built around a simulated B2B industrial distribution company.

The project uses deliberately imperfect data across multiple business systems to simulate the type of analytical work encountered in a real organization.

## Business Environment

The dataset contains data from:

- ERP — customers, products, orders, order items, suppliers and returns
- Finance — invoices and payments
- CRM — accounts, opportunities and sales representatives
- WMS — inventory data
- Legacy business systems

The data covers approximately 2021–2026 and includes thousands of customers, products and transactional records.

## Tools

- PostgreSQL
- Python
- Pandas
- Excel
- Power BI

## What I'm Working On

The project progresses from fundamental analysis toward open-ended business investigations.

Current areas include:

- Revenue and sales analysis
- Gross profit and margin analysis
- Customer and product performance
- Data quality validation
- Multi-table analysis
- Financial analysis
- Data cleaning and reconciliation
